# Capacita+

## Projeto Final - Programa Transforma Futuros

### ODS principal
ODS 4 - Educação de Qualidade

### ODS complementar
ODS 8 - Trabalho Decente e Crescimento Econômico

### Público-alvo
Pessoas maiores de 18 anos interessadas em capacitação profissional.

### Problema
Pessoas interessadas em melhorar sua qualificação profissional podem ter dificuldade para encontrar, organizar e acompanhar informações sobre cursos de capacitação.

### Solução
Desenvolver uma plataforma web para centralizar cursos de capacitação profissional e permitir o gerenciamento de instrutores, cursos e inscrições.

### CRUDs
1. Instrutores
2. Cursos
3. Inscrições

### Tecnologias obrigatórias
- MySQL
- Java
- ReactJS
